Referências da Alura: Conheça as principais plataformas low code/no code recomendadas para o desenvolvimento de aplicações modernas.

🌐 NO CODE

Plataformas que permitem criar aplicações completas sem escrever código.

Bubble

Aplicações web completas, MVPs, dashboards interativos e plataformas de marketplace.

→ bubble.io
Wix

Criação de sites profissionais, portfólios e lojas online com design intuitivo.

→ wix.com
Webflow

Design web responsivo com controle visual avançado, sem perder qualidade.

→ webflow.com
Adalo

Criação de aplicações mobile nativas sem programação, para iOS e Android.

→ adalo.com
Notion

Bases de dados, wikis, automações e estruturação de processos colaborativos.

→ notion.so
Airtable

Automação de processos, gerenciamento de projetos e integração com outras ferramentas.

→ airtable.com

⚡ LOW CODE

Plataformas que combinam interface visual com código para soluções enterprise.

OutSystems

Criação rápida de softwares empresariais com escalabilidade e integração robusta.

→ outsystems.com
Power Apps (Microsoft)

Soluções empresariais internas com integração ao ecossistema Microsoft.

→ powerapps.microsoft.com
Mendix

Desenvolvimento ágil de aplicações corporativas com colaboração em tempo real.

→ mendix.com
FlutterFlow

Apps multi-plataforma (iOS, Android, Web) com pouco código e alta qualidade.

→ flutterflow.io
AppSheet (Google Cloud)

Inteligência Artificial integrada para criar aplicações smart com automações.

→ appsheet.com

🔌 AUTOMAÇÃO & 💡 VIBECODE

Plataformas para integração, workflows e codificação leve.

Zapier

Integrações entre aplicações e automação de workflows sem programação.

→ zapier.com
Make (Integromat)

Automação visual de processos e integrações complexas entre serviços.

→ make.com
Firebase (Google)

Backend leve com banco de dados em tempo real, autenticação e hospedagem.

→ firebase.google.com
Supabase

Alternativa open source ao Firebase com PostgreSQL e APIs automáticas.

→ supabase.com
Replit

Ambiente de desenvolvimento online para prototipagem rápida e aprendizado.

→ replit.com

💡 Dicas para Escolher a Melhor Plataforma

  • Análise do Escopo: Sites? Apps? Automações? Escolha de acordo com seu objetivo.
  • Integração: Verifique se a plataforma se integra com ferramentas que você já usa.
  • Escalabilidade: Seu projeto vai crescer? Prefira low code para melhor controle.
  • Custo: Algumas têm planos gratuitos ou trial, teste antes de decidir.
  • Comunidade: Comunidades ativas oferecem tutoriais, templates e suporte.
  • Curva de Aprendizado: No code é mais intuitivo; low code exige um pouco mais de lógica.
